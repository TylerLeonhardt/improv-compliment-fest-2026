# Compliment Fest!! 🪩

**An Improvised Improv Festival**

📅 Sunday, August 30th, 2026 · 1:00 PM – 5:00 PM  
📍 Dr. Blanche Lavizzo Park Amphitheatre, Central District, Seattle  
💰 Free! (with optional donation)

A cross between an open mic and a festival — show up with an idea for a 20-minute improv set, form a team, toss your idea in a hat, and the lineup gets built at random. Fair chances for both existing teams and day-of teams.

Celebrating 300+ members of the Compliment Circle Discord community. ✨
